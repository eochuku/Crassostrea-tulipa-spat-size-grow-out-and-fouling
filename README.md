This repository contains data files with data analysed for the paper titled: 
Depth, substrate, site, and season effects on post-set spat size, grow-out and fouling in a tropical mangrove oyster aquaculture.

The data includes:
1. Post-set spat sizes data
2. Environmental data with mean monthly spat sizes data
3. Grow-out performance data
4. Survival related to grow-out experiment
5. Fouling data - raw records of fouling
6. Fouling data - processes with species level scores
7. Fouling data - further processed including collector face combinations with thin experimental design
8. Fouling species key
